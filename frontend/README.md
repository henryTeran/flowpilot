# Frontend FlowPilot Institut Manager

Interface React/TypeScript du MVP.

## Démarrage

```powershell
npm install
npm run dev
```

Puis ouvrir :

```text
http://localhost:5173
```

Le frontend attend le backend sur :

```text
http://localhost:8001/api/v1
```

Si besoin, copier `.env.example` vers `.env` et adapter `VITE_API_URL`.
